# Hand-pinning nvidia-* here collided with the base image: torch 2.13.0 requires

# only a warning, leaving torch running against a cuDNN it was not built for.
# The extras ask for `nvidia-cudnn-cu13~=9.0`, which the already-installed
# version satisfies, so pip leaves torch's copy alone and adds only what ORT
